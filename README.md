# DualPlay

Console-first libretro frontend for dual-screen Android handhelds (AYN Thor first). The game runs on the
top display through our LibretroDroid fork; DualDex runs on the bottom display and reads core memory
in-process.

Status: stage-1 spike. See [docs/spec.md](docs/spec.md) and [docs/plan-stage1-spike.md](docs/plan-stage1-spike.md).

```
git clone --recurse-submodules https://github.com/Darkaxt/DualPlay.git
```
